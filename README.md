# Planlens

Review Terraform and OpenTofu plan JSON in Cursor and VS Code. Values the plan marks sensitive are redacted. Plan JSON is not uploaded. Not affiliated with HashiCorp.

Planlens is **not listed** on the VS Code Marketplace or OpenVSX yet. Do not treat this repository as a store.

## Support

1. In the editor: Command Palette → **Planlens: Copy Diagnostics** (clipboard only; no license key; no plan JSON).
2. Open a [GitHub issue](https://github.com/PixelPounder/planlens/issues). Do not paste license keys, plan JSON, or `.tf` files.

Vulnerabilities: [private advisory](https://github.com/PixelPounder/planlens/security/advisories/new), not a public issue. See [SECURITY.md](./SECURITY.md).
