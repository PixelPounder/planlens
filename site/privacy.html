Planlens

Privacy policy

Last updated: 2026-08-27

Planlens reviews Terraform and OpenTofu plan JSON inside your editor.

No first-party telemetry

The packaged Planlens extension does not include first-party telemetry, analytics, crash reporting, usage tracking, or advertising identifiers. Planlens does not send install counts, feature-usage events, or plan contents to infrastructure we operate. The only Planlens-initiated HTTP client is Polar license validation, described below. This was verified for 0.1.3 by inspecting the packaged VSIX JavaScript and is the standing rule for later versions unless this page is updated in the same release as a network change.

Processed locally

Plan files you open, and the JSON from Run Plan, are parsed on your computer. Planlens does not upload plan JSON. Values Terraform/OpenTofu mark sensitive are redacted. Secrets not marked sensitive can still appear in the review UI.

Network

Opening a plan JSON file does not make a Planlens network call. If you enter a Planlens Pro license key, or you invoke a Pro command, and a Polar organization id is configured, Planlens POSTs that key and organization id to https://api.polar.sh/v1/customer-portal/license-keys/validate. That request does not include plan JSON, source code, or environment variables.

Planlens: Copy Diagnostics copies a redacted environment report to your clipboard. It does not make a Planlens network call. The report includes editor/OS versions and whether a license key is present. It does not include the license key, plan JSON, PATH, or workspace paths.

Run Plan executes the first matching terraform/tofu binary on the editor process PATH after you confirm. Those CLIs may contact providers, backends, and registries, and may execute provider plugins from the working directory, according to your configuration. That traffic is not sent to Planlens. Planlens does not upload plan JSON. Cursor, VS Code, and the extension marketplace make their own network calls outside Planlens’s control.

Support submissions

If you paste diagnostics or issue text into GitHub, that content is public and is not sent by the extension itself. Do not paste license keys, plan JSON, or Terraform source. Purchases are handled by Polar as merchant of record. Polar’s privacy policy applies to checkout.
