Planlens

Read the plan before you apply it.

Open JSON from terraform show -json or tofu show -json. Planlens lists creates, updates, destroys, and replacements. Values the plan marks sensitive are redacted. Unmarked secrets in a plan can still appear. Plan JSON is not uploaded by Planlens.

Planlens is not affiliated with HashiCorp. Terraform is a HashiCorp trademark. OpenTofu is a Linux Foundation trademark.

Free review. Pro is $49 once.

Install from the VS Code Marketplace or OpenVSX (Cursor). Checkout link is added when Polar is live.

Free

  • Open a plan JSON file in Cursor or VS Code
  • Filter and search resource changes
  • Plan-marked sensitive values redacted (unmarked secrets can still appear)
  • Planlens does not upload plan JSON

Pro

  • Run terraform or tofu plan from the editor
  • Copy a PR markdown summary
  • Compare two plans
  • Danger digest for destroys, replacements, IAM, network, and data stores

Produce a plan JSON

terraform plan -out=plan.bin
terraform show -json plan.bin > tfplan.json

Privacy

Support

In the editor: Command Palette → Planlens: Copy Diagnostics. That copies a redacted report to the clipboard. It does not send network traffic. Do not paste license keys, plan JSON, or Terraform source. Then open a GitHub issue.

Planlens is not listed on the VS Code Marketplace or OpenVSX yet. Do not paste license keys or plan JSON into issues.
